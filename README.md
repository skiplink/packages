# Skiplink packages

Source for the npm packages behind [Skiplink](https://skiplink.dev) — an accessibility
gate for CI that runs axe-core against your pages and fails the build only on
violations you have not already accepted.

## How this repository works

The packages are developed in a private source tree and published here by a script
on every release. **Issues are welcome here**, and pull requests are read here and
applied upstream — see [CONTRIBUTING.md](CONTRIBUTING.md). 1.0.0 was published to npm
by hand; later releases are published from this repository by the
[Publish](.github/workflows/publish.yml) workflow, with
[provenance](https://docs.npmjs.com/generating-provenance-statements), so each tarball
on npm links back to the commit and the run that built it.

`internal/scan/schema/testdata/` and `data/wcag.json` are test fixtures: the
fingerprint vectors and standard map generated by the hosted API's implementation,
and the WCAG criteria the editor integration documents. The parity tests in
`packages/core` read them, so a change to fingerprinting here that disagrees with
the hosted side fails CI.

```bash
npm install && npx playwright install chromium && npm test
```

## Fingerprints are a frozen contract

`packages/core/src/fingerprint.js` decides which violation is "the same violation" as
one a team has already accepted in a committed baseline. The hosted API implements the
identical scheme and both write to the same baseline file, so the two must agree
exactly. Changing either would invalidate every baseline in the field, so it does not
happen — a new identity scheme would be a new field.
